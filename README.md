# 🏥 Hospital Management Dashboard

## 📊 Overview
The **Hospital Management Dashboard** is a data analytics project designed to provide actionable insights into hospital operations, patient trends, and financial performance.

This dashboard helps stakeholders monitor key metrics such as patient count, billing, payments, and department-wise performance.

---

## 🚀 Key Features

- 📌 Total Patients Tracking (10K+ records)
- 👨‍⚕️ Doctor Distribution by Specialization
- 💰 Financial Insights (Total Bill, Received, Pending)
- 💳 Payment Mode Analysis
- 🦠 Disease Trends Analysis
- 🌍 State-wise Financial Breakdown
- 🎯 Interactive Filters (State & City)

---

## 📈 Dashboard Highlights

### 🔹 KPIs
- Total Patients: **10K**
- Average Age: **46**
- Total Doctors: **9465**
- Total Bill Amount: **1.03 Billion**
- Amount Received: **510.23 Million**
- Pending Amount: **523.18 Million**

---

## 📊 Insights Generated

- **General Medicine & Neurology** have the highest patient load  
- **Hypertension & COVID-19** show lower patient counts compared to common diseases  
- Payment distribution is **evenly spread across modes**  
- Significant **pending payments indicate cash flow gaps**  
- State-level analysis reveals **uneven revenue distribution**
